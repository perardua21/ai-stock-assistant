# 급락 위험 검토 절차

1. 모델 신호 확인: get_crash_signal
   - 급락 확률과 기준 비율(시장 평균 급락 비율)을 비교한다. 기준 비율의 3배 이상이면 주의 대상이다.
   - SHAP 상위 피처가 무엇인지 본다. 변동성·고점 대비 하락·외국인 순매도처럼 가격에서 이미 보이는 위험인지 확인한다.
   - Chronos 하위 5% 시나리오(q05_ret_min)가 -10%보다 낮으면 꼬리 위험이 크다는 뜻이다.

2. 가격·수급 확인: get_price_summary
   - 최근 5일·20일 수익률, 거래량 급증(volume_ratio_20 > 1), 외국인 연속 순매도 일수를 본다.
   - 이미 크게 하락한 직후라면 추가 하락과 반등 가능성을 모두 적는다.

3. 공시 확인: search_disclosures (최근 30일)
   - disclosure_risk 스킬의 위험 등급표로 분류한다.
   - high 등급 공시가 있으면 모델 확률이 낮아도 judgment를 최소 medium으로 올린다.

4. 뉴스 확인: search_news (종목명으로 검색, 최근 기사 10건)
   - 실적 쇼크, 소송, 규제, 대주주 매도, 거래정지 가능성 같은 악재를 찾는다.
   - 제목만 보고 판단하지 말고 요약까지 읽는다. 같은 사건의 중복 기사는 하나로 센다.

5. 과거 판단 확인: recall_memory
   - 같은 종목에서 예전에 틀린 적이 있으면 그 이유를 이번 판단에 반영한다.

6. **판단**
   - agent_probability: 모델 확률에서 시작해 근거가 있을 때만 조정한다 (±0.3 이내).
   - judgment: high(급락 가능성이 뚜렷함) / medium(주의) / low(특이 위험 없음)
   - reasons에는 어떤 근거가 판단을 바꿨는지(또는 바꾸지 않았는지) 적는다.
